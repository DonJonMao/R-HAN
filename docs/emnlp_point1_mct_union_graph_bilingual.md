# Point 1: Learnable MCT-Based Union Graph MAS Architecture

## Revision Note

This version rewrites the first contribution in a more academic form. The previous draft exposed many implementation-specific discrete rules, such as fixed top-k selection, hand-designed quality/diversity scores, and manually calibrated edge logits. In this revision, these components are reframed as learnable modules: a neural architecture policy proposes candidate multi-agent graphs, a learned value/acquisition model guides Monte-Carlo-tree-style exploration, and a neural union-graph composer merges candidate topologies through differentiable evidence aggregation. The goal is to preserve the high-level idea of "tree search generates multiple MAS structures, then union graph merging constructs a task-specific reasoning substrate" while avoiding hand-coded discrete policies as much as possible.

## English Draft

### Learnable MCT-based Union-Graph Construction for Multi-Agent Reasoning

A central design choice in R-HAN is to decouple the discovery of a useful multi-agent structure from the subsequent execution of that structure. Instead of relying on a single hand-designed workflow, R-HAN first explores a family of candidate multi-agent system (MAS) structures and then composes them into a task-specific union graph. However, a direct engineering implementation of this idea can easily degenerate into a collection of discrete heuristics: manually enumerated templates, fixed top-k filters, hand-crafted diversity scores, and calibrated edge priors. To make the method suitable as a general research contribution, we formulate this stage as a fully learnable architecture inference problem. The tree is used as a search procedure, but the policies that propose, rank, expand, and merge structures are parameterized and trained from execution feedback.

For an input instance `x`, R-HAN infers a distribution over latent MAS architectures rather than selecting from a fixed set of templates. Let `z` denote a latent architecture state. It encodes role semantics, agent assignments, prompt behavior, and graph connectivity in a continuous representation:

```text
z = (H_V, H_E, H_P)
```

where `H_V` contains node and role embeddings, `H_E` contains edge and communication embeddings, and `H_P` represents prompt or instruction behavior in a latent space. A concrete executable topology can be decoded from `z` when rollout execution is required, but the search policy itself operates over latent states. This formulation avoids treating templates, role assignments, and prompt slots as independent discrete knobs. Instead, they become coupled decisions generated by a neural architecture policy.

The first module is a task-conditioned architecture generator:

```text
q_theta(z_0 | x)
```

which produces a distribution over root architecture states. The generator conditions on the input question, dataset metadata, and learned agent representations. Rather than selecting a fixed set of candidate agents by thresholding similarity scores, it constructs soft role-agent compatibility distributions. Each role is represented by a latent query vector, each agent by a learned capability vector, and the generator produces assignment probabilities through attention. The same mechanism also predicts initial communication tendencies between latent roles. As a result, the initial search frontier is not a set of manually specified root templates, but a learned posterior over plausible MAS structures for the current task.

Tree expansion is also parameterized. Given a parent latent architecture `z`, the expansion policy

```text
p_theta(z' | z, x, T)
```

proposes child architectures conditioned on the input `x` and the current search tree context `T`. Conceptually, a child may refine the workflow, reassign responsibility among agents, alter verification strength, or modify information flow. Unlike a discrete action set such as `ChangeTemplate` or `SwapAgent`, these changes are represented as transformations in latent architecture space. The expansion policy can be implemented as a graph neural network or transformer over the current architecture state, producing updated node embeddings, edge logits, and prompt-behavior embeddings. During training, the policy is optimized to assign higher probability to expansions that later yield better execution outcomes.

The Monte-Carlo-tree component is retained, but its selection rule is learned. Each explored node `i` stores its latent state `z_i`, rollout traces, and observed feedback. A learned value model estimates the expected utility of continuing from that node:

```text
V_phi(z_i, x, T_i)
```

where `T_i` summarizes the local search history around node `i`. A learned uncertainty or epistemic-risk head estimates how reliable this prediction is. Parent selection is then driven by a trainable acquisition model:

```text
A_psi(z_i, x, T_i) = f_psi(V_phi(z_i, x, T_i), U_phi(z_i, x, T_i), C_i)
```

where `C_i` denotes contextual search features such as visit history, rollout diversity, and disagreement among evaluators. Importantly, the acquisition function is not a fixed PUCT formula with manually chosen constants. It is a learned policy over tree nodes, trained to balance exploitation, exploration, and structural diversity according to downstream task reward. The tree therefore provides an organized memory of explored architectures, while the decision of where to expand is learned from data.

Candidate evaluation is likewise modeled as learned reward estimation rather than a cascade of hard-coded tiers. Executing a decoded topology produces a trace containing intermediate messages, verifier judgments, final answer candidates, token cost, latency, and task reward when supervision is available. A neural evaluator maps this trace into a calibrated scalar reward and auxiliary diagnostic signals:

```text
r_hat = R_omega(x, G_z, trace)
```

where `G_z` is the decoded graph corresponding to latent state `z`. The evaluator can be trained from labeled task outcomes, self-consistency signals, verifier feedback, and preference comparisons between candidate rollouts. If multiple evaluation sources are available, they are fused by a learned calibration layer instead of manually assigning them to proxy, tier-1, and tier-2 stages. This makes the search objective smoother: the value model, expansion policy, and evaluator can be jointly improved as more rollouts are collected.

After search, R-HAN does not collapse the explored tree to a single best topology. The purpose of the first stage is to recover a structured distribution over useful reasoning pathways. Let the search produce a set of latent candidate graphs `{z_1, ..., z_m}` with rollout evidence `{e_1, ..., e_m}`. A topology evidence model computes posterior weights:

```text
omega_i = softmax(g_eta(z_i, e_i, x))
```

These weights replace fixed top-k selection. They determine how much each candidate topology should contribute to the union graph, but they remain differentiable and trainable. Diversity is also learned: instead of manually combining edge diversity, agent diversity, and template diversity, the model learns a repulsion or coverage term in latent graph space. This encourages the posterior to place mass on candidates that are both useful and complementary, while avoiding redundant copies of the same reasoning pattern.

The union graph is constructed by neural evidence aggregation. For every possible node `v` and edge `u -> v` appearing in the candidate graph family, the composer builds an evidence representation by attending over all candidate topologies that support it:

```text
h_v = Attn_eta({omega_i, h_v^{(i)}, e_i : v in G_i})
h_uv = Attn_eta({omega_i, h_uv^{(i)}, e_i : (u,v) in G_i})
```

The node posterior and edge posterior are then predicted by learned functions:

```text
p_v = sigma(Node_eta(h_v, x))
p_uv = sigma(Edge_eta(h_u, h_v, h_uv, x))
```

These posteriors replace support counts, support ratios, average parent scores, and hand-coded initial keep logits. They still capture the same underlying evidence: whether a node or edge appears in strong rollouts, whether it appears across complementary structures, and whether it contributes to reliable final answers. But the mapping from evidence to graph inclusion is learned, not prescribed. During execution, the union graph can be used as a soft graph with edge probabilities, or sparsified by a differentiable sparse transformation such as sparsemax or entmax when a compact runtime graph is required.

This learnable union-graph composer has two important benefits. First, it preserves uncertainty. If several candidate graphs disagree about whether a verifier should receive information from a solver, the resulting edge posterior can remain uncertain instead of being forced into a binary merge decision. The second-stage runtime can then resolve the uncertainty through memory, verifier feedback, or additional rollout evidence. Second, it creates a direct training path from downstream reasoning success back to graph construction. If an edge repeatedly helps recovery or prevents hallucinated answers, the edge posterior model can learn to assign it higher probability in similar future tasks.

The resulting first-stage output is therefore not a single architecture and not a rule-based union of topologies. It is a task-conditioned probabilistic union graph:

```text
G_union(x) = (V, E, p_V, p_E, H)
```

where `p_V` and `p_E` are learned node and edge posteriors, and `H` contains latent node and edge states passed to the second-stage runtime. The graph may be frozen as the structural substrate before later execution, but its construction is fully learnable. Later modules, such as latent memory routing, edge activation, verifier-triggered recovery, and final candidate selection, operate on this learned graph rather than on a manually assembled workflow.

This formulation gives R-HAN a cleaner academic contribution. MCT provides a search scaffold for exploring multiple plausible MAS structures; neural policies control expansion, evaluation, and acquisition; and the union graph is produced by differentiable evidence aggregation over searched topologies. The method therefore preserves the interpretability and modularity of graph-based MAS reasoning while replacing engineering-specific discrete policies with learnable architecture inference.

## 中文翻译

### 基于可学习 MCT 的多智能体 Union Graph 构建

R-HAN 的一个核心设计，是将“发现有用的多智能体结构”和“在该结构上执行推理”解耦。系统不依赖单一人工设计的 workflow，而是先探索一族候选多智能体系统（MAS）结构，再将它们组合成面向当前任务的 union graph。不过，如果直接按照工程方式实现，这个想法很容易退化成一组离散启发式规则：人工枚举模板、固定 top-k 过滤、手写 diversity score、人工校准 edge prior。为了让这一阶段更适合作为学术方法贡献，我们将其重新表述为一个完全可学习的架构推断问题。树结构仍然作为搜索过程使用，但用于提出结构、排序结构、扩展结构和合并结构的 policy 都由参数化模型学习得到，并通过执行反馈训练。

对于输入样本 `x`，R-HAN 推断的是 latent MAS architecture 的分布，而不是从固定模板集合中选择一个结构。令 `z` 表示 latent architecture state，它用连续表示编码角色语义、agent 分配、prompt 行为和图连接关系：

```text
z = (H_V, H_E, H_P)
```

其中 `H_V` 包含节点和角色 embedding，`H_E` 包含边和通信关系 embedding，`H_P` 表示 latent prompt 或 instruction 行为。当需要实际 rollout 执行时，可以从 `z` 解码出具体可执行拓扑；但搜索 policy 本身在 latent state 上运行。这样就避免了将 template、role assignment 和 prompt slot 当作彼此独立的离散旋钮，而是把它们视为由神经架构 policy 联合生成的耦合决策。

第一个模块是任务条件化的架构生成器：

```text
q_theta(z_0 | x)
```

它产生 root architecture states 的分布。该生成器以输入问题、数据集元信息和可学习 agent 表示为条件。系统不再通过相似度阈值选择固定候选 agent 集，而是构造软的 role-agent compatibility distribution。每个 role 由 latent query vector 表示，每个 agent 由可学习 capability vector 表示，生成器通过 attention 得到角色分配概率。同一机制也会预测 latent roles 之间的初始通信倾向。因此，初始搜索 frontier 不再是一组人工指定的 root templates，而是当前任务下 plausible MAS structures 的学习后验。

树扩展同样由参数化模型控制。给定 parent latent architecture `z`，扩展 policy

```text
p_theta(z' | z, x, T)
```

会在输入 `x` 和当前搜索树上下文 `T` 的条件下提出 child architectures。从概念上看，一个 child 可能细化 workflow、重新分配 agent 职责、改变验证强度，或调整信息流。但这些变化不再表示为 `ChangeTemplate`、`SwapAgent` 这类离散动作，而是表示为 latent architecture space 中的变换。扩展 policy 可以实现为作用在当前架构状态上的 graph neural network 或 transformer，输出更新后的 node embeddings、edge logits 和 prompt-behavior embeddings。训练时，该 policy 会被优化为给后续执行效果更好的扩展分配更高概率。

Monte-Carlo-tree 组件仍然保留，但节点选择规则变为可学习。每个已探索节点 `i` 存储其 latent state `z_i`、rollout trace 和观测反馈。可学习 value model 估计从该节点继续搜索的期望收益：

```text
V_phi(z_i, x, T_i)
```

其中 `T_i` 表示节点 `i` 周围的局部搜索历史。另一个不确定性或 epistemic-risk head 估计该预测的可靠程度。parent selection 由可训练 acquisition model 驱动：

```text
A_psi(z_i, x, T_i) = f_psi(V_phi(z_i, x, T_i), U_phi(z_i, x, T_i), C_i)
```

其中 `C_i` 表示访问历史、rollout 多样性、不同 evaluator 之间的分歧等搜索上下文特征。关键在于，acquisition function 不再是带人工常数的固定 PUCT 公式，而是一个学习得到的 tree-node policy。它通过下游任务 reward 学习如何平衡 exploitation、exploration 和结构多样性。因此，tree 提供的是被探索架构的组织化记忆，而“接下来扩展哪里”由数据驱动的模型决定。

候选结构评测也被建模为可学习 reward estimation，而不是硬编码的多级评测 cascade。执行一个解码后的 topology 会产生 trace，其中包含中间消息、verifier 判断、最终答案候选、token cost、latency，以及在有监督时的任务 reward。神经 evaluator 将该 trace 映射为校准后的标量 reward 和辅助诊断信号：

```text
r_hat = R_omega(x, G_z, trace)
```

其中 `G_z` 是 latent state `z` 对应的解码图。这个 evaluator 可以从有标签任务结果、自一致性信号、verifier feedback 以及候选 rollout 之间的 preference comparison 中训练。如果存在多个评测来源，它们由可学习 calibration layer 融合，而不是被人工分配成 proxy、tier-1 和 tier-2 阶段。这样搜索目标更加平滑：value model、expansion policy 和 evaluator 都可以随着收集到更多 rollout 而联合改进。

搜索结束后，R-HAN 不会把整棵搜索树压缩成单个最优 topology。第一阶段的目的，是恢复一组有用推理路径的结构化分布。令搜索产生 latent candidate graphs `{z_1, ..., z_m}` 及其 rollout evidence `{e_1, ..., e_m}`。topology evidence model 计算每个候选图的后验权重：

```text
omega_i = softmax(g_eta(z_i, e_i, x))
```

这些权重替代固定 top-k 选择。它们决定每个候选 topology 应该对 union graph 贡献多少证据，同时保持可微、可训练。多样性也由模型学习：系统不再人工组合 edge diversity、agent diversity 和 template diversity，而是在 latent graph space 中学习 repulsion 或 coverage 项。这鼓励 posterior 将概率质量放在既有用又互补的候选结构上，同时避免重复保留同一种推理模式的多个副本。

union graph 通过神经证据聚合构建。对于出现在候选图族中的每个可能节点 `v` 和每条可能边 `u -> v`，composer 会对所有支持该节点或边的候选 topology 做 attention 聚合：

```text
h_v = Attn_eta({omega_i, h_v^{(i)}, e_i : v in G_i})
h_uv = Attn_eta({omega_i, h_uv^{(i)}, e_i : (u,v) in G_i})
```

随后，节点后验和边后验由可学习函数预测：

```text
p_v = sigma(Node_eta(h_v, x))
p_uv = sigma(Edge_eta(h_u, h_v, h_uv, x))
```

这些 posterior 替代了 support count、support ratio、average parent score 和人工 initial keep logit。它们仍然捕捉同样的底层证据：某个节点或边是否出现在高质量 rollout 中，是否跨互补结构反复出现，是否有助于获得可靠最终答案。但从证据到图保留概率的映射不再是人工规定，而是通过训练学习得到。在执行阶段，union graph 可以作为带 edge probability 的软图使用；如果需要紧凑 runtime graph，也可以通过 sparsemax 或 entmax 这类可微稀疏变换得到稀疏结构。

这种可学习 union-graph composer 有两个重要好处。第一，它保留了不确定性。如果多个候选图对 verifier 是否应该接收 solver 信息存在分歧，最终 edge posterior 可以保持不确定，而不是被迫做二值合并。第二阶段 runtime 可以再通过 memory、verifier feedback 或额外 rollout evidence 解决这种不确定性。第二，它建立了从下游推理成功反传到图构建过程的训练路径。如果某条边反复帮助系统恢复错误答案或避免幻觉，edge posterior model 就能在相似未来任务中学会给它更高概率。

因此，第一阶段的输出既不是单个 architecture，也不是基于规则的拓扑并集，而是一张任务条件化的概率 union graph：

```text
G_union(x) = (V, E, p_V, p_E, H)
```

其中 `p_V` 和 `p_E` 是学习得到的节点和边后验，`H` 包含传递给第二阶段 runtime 的 latent node/edge states。该图可以在后续执行前被冻结为结构基底，但它的构建过程是完全可学习的。后续模块，例如 latent memory routing、edge activation、verifier-triggered recovery 和最终候选选择，都运行在这张学习得到的图上，而不是运行在人工拼装的 workflow 上。

这种表述让 R-HAN 的第一个贡献更加清晰：MCT 提供用于探索多个 plausible MAS structures 的搜索脚手架；神经 policy 控制 expansion、evaluation 和 acquisition；union graph 则由搜索拓扑上的可微证据聚合产生。因此，该方法在保留 graph-based MAS reasoning 的可解释性和模块化优势的同时，将工程化离散 policy 替换为可学习的 architecture inference。
